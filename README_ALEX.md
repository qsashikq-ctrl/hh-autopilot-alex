# HH Autopilot Alex — тестовая версия

Цель этой сборки — сначала доказать полный цикл **на одном реальном отклике**, и только потом включать автономность.

## Что уже умеет

- Работает как Telegram-бот.
- HH-авторизация идёт без GUI: `/login` → HH отправляет код → код вводится в Telegram → cookies сохраняются.
- Можно прислать боту ссылку `https://hh.ru/vacancy/...`.
- Бот читает вакансию, показывает краткую карточку и кнопку **Откликнуться**.
- Перед откликом показывает универсальное сопроводительное письмо.
- Дубликаты откликов блокируются.
- Есть SQLite-статистика.
- Есть поиск по целевым управленческим ролям.
- Фоновый автопоиск предусмотрен, но **автоотклик выключен по умолчанию**.

## Важно

Это не обход CAPTCHA и не попытка скрыть автоматизацию. Если HH покажет CAPTCHA или изменит интерфейс, бот остановит соответствующее действие и попросит ручную проверку.

## Что понадобится для запуска на VPS

1. Ubuntu 24.04 LTS.
2. Python 3.11+.
3. Chromium через Playwright.
4. Telegram Bot Token.
5. Telegram numeric user ID.
6. Номер HH в `HH_LOGIN`.

Секреты не хранить в GitHub. Они задаются только через `.env` на сервере.

## Проверка перед автономным режимом

1. `/start`
2. `/login`
3. Ввести код HH в Telegram.
4. Прислать **одну** вакансию HH ссылкой.
5. Нажать **Откликнуться**.
6. Проверить в разделе «Отклики» на HH, что отклик появился.
7. Только после этого можно включать `AUTO_APPLY_ENABLED=true`.

## Целевые роли

- Директор по продажам
